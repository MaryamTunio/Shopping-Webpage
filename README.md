# ShopEase - Dynamic Product Showcase

ShopEase is a clean, modern, and fully responsive e-commerce product showcase webpage. It dynamically renders a catalog of products and features an interactive filtering system, allowing users to browse items by categories seamlessly without reloading the page.

## ✨ Features

- **Dynamic DOM Rendering:** Products are injected dynamically from a centralized JavaScript data array.
- **Real-Time Category Filtering:** Quick-response filter buttons sort products instantly by categories (*All*, *Electronics*, *Clothing*, *Home*).
- **Responsive Layout:** Designed to scale beautifully across devices, from desktop screens to mobile phones.
- **Clean UI:** Includes subtle styling components such as product card hover animations, price chips, and star rating metrics.
